# CampusSpend

CampusSpend is a Java command-line expense tracker designed for student use. It supports income and expense records, categories, monthly summaries, budgets, and transaction management.

## Technologies
- Java 17+
- Maven
- SQLite
- JUnit 5

## Run
```bash
mvn clean test
mvn compile exec:java "-Dexec.mainClass=com.campusspend.App"
```

The application creates `campusspend.db` automatically on first run.

## Main features
- Student registration and login
- Add income and expenses
- Categorize transactions
- View transaction history
- Monthly income/expense/balance summary
- Set a monthly budget and see remaining amount
- Delete own transactions
- Input validation and error handling

## Academic focus
The project demonstrates classes and objects, encapsulation, enum types, collections, streams, JDBC, file/database persistence, exception handling, date/time APIs, modular packages, and JUnit testing.
